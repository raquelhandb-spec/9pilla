# Guia de Compliance para Criadores de Conteúdo Financeiro

## 📋 Sobre

Este é um guia completo e interativo sobre como compartilhar seu diário de operações com opções de forma **educacional e segura**, sem violar as regras da CVM e sem arriscar a suspensão de sua conta no Instagram ou Facebook.

O guia cobre:
- **Regras da CVM** (Comissão de Valores Mobiliários)
- **Políticas do Instagram e Facebook** (Meta Platforms)
- **Melhores práticas** baseadas em ANBIMA e especialistas
- **Disclaimers prontos** para copiar e colar
- **Checklist interativo** antes de publicar

## 🚀 Como Usar

### Opção 1: Acessar a Página Web Interativa

1. Navegue até a pasta `client/`
2. Execute `pnpm install` (ou `npm install`)
3. Execute `pnpm dev` (ou `npm run dev`)
4. Abra `http://localhost:5173` no navegador

### Opção 2: Usar o Template Markdown

Veja o arquivo `TEMPLATE_POST_COMPLIANCE.md` para um template reutilizável que você pode usar como base para cada novo post sobre operações com opções.

## 🎨 Design

O guia foi desenvolvido com a filosofia **"Legal Navigator"** — um design editorial sofisticado com:
- **Tipografia**: Playfair Display (headings) + Lato (body)
- **Paleta**: Cream (#F5F0E8), Forest Green (#1C3B2D), Golden Mustard (#C9A227)
- **Layout**: Editorial magazine com pull quotes e citações legais

## ⚖️ Resumo das Regras Principais

| Ação | Status | Detalhe |
|------|--------|---------|
| Compartilhar operações encerradas com contexto educacional | ✅ Permitido | Foco pedagógico, sem recomendação |
| Usar disclaimer claro em todos os posts | ✅ Permitido | Elemento essencial de boa-fé |
| Diário gratuito sem assinatura ou mensalidade | ✅ Permitido | Reduz risco de ser regulado |
| Cobrar mensalidade ou assinatura | ❌ Proibido | Caracteriza atividade profissional regulada |
| Usar linguagem apelativa ("garanto", "infalível") | ❌ Proibido | Viola políticas CVM e Meta |
| Recomendar explicitamente compra/venda de ativos | ❌ Proibido | Exige habilitação CNPI |
