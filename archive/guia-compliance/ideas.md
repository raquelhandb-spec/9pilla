## Contexto

## Ideia 1: "Regulatory Blueprint" — Estética de Documentação Técnica Refinada

**Design Movement**: Swiss International Style + Editorial Financeiro

**Core Principles**:
- Precisão visual que transmite seriedade regulatória
- Hierarquia tipográfica rigorosa, como documentos oficiais modernizados
- Uso de cor como sistema semântico (verde = permitido, vermelho = proibido, âmbar = atenção)
- Grid assimétrico com colunas de largura variável

**Color Philosophy**:
- Fundo: branco quase puro com leve tom de papel (#FAFAF8)
- Primária: azul-marinho profundo (#0F2B5B) — autoridade e confiança
- Acento: verde-esmeralda (#1A7A4A) para zonas seguras
- Alerta: âmbar escuro (#C47A00) para zonas de atenção
- Perigo: vermelho-tijolo (#B52B2B) para zonas proibidas

**Layout Paradigm**:
- Sidebar fixa à esquerda com navegação por seções (CVM, Instagram/Meta, Melhores Práticas)
- Conteúdo principal em coluna central larga com margem direita para notas/citações
- Cards de regras com bordas coloridas semânticas (esquerda colorida por status)

**Signature Elements**:
- Ícones de "semáforo regulatório" (verde/âmbar/vermelho) em cada regra
- Citações de documentos oficiais em blocos destacados com fonte monoespaçada
- Linha do tempo horizontal mostrando evolução regulatória

**Interaction Philosophy**:
- Tabs para alternar entre "O que PODE", "O que NÃO PODE" e "Zona Cinzenta"
- Accordion para expandir detalhes de cada regra
- Tooltip com fonte legal ao passar sobre termos técnicos

**Animation**:
- Entrada suave das seções (fade + slide up)
- Indicador de progresso de leitura no topo
- Hover em cards com elevação sutil de sombra

**Typography System**:
- Títulos: IBM Plex Serif Bold — autoridade editorial
- Corpo: IBM Plex Sans Regular — leitura técnica confortável
- Citações legais: IBM Plex Mono — distinção de fonte oficial

## Ideia 2: "Compliance Dashboard" — Painel Analítico Moderno

**Design Movement**: Data Dashboard + Fintech UI

**Core Principles**:
- Interface de painel com cards informativos organizados por categoria
- Visualização de dados com gráficos interativos mostrando o "mapa de risco"
- Linguagem visual de aplicativo financeiro profissional
- Dark mode como padrão — associação com plataformas de trading

**Color Philosophy**:
- Fundo: cinza-carvão escuro (#0D1117) com variações sutis
- Cards: #161B22 com borda sutil
- Primária: azul-elétrico (#2563EB)
- Verde: #10B981 para status "seguro"
- Âmbar: #F59E0B para "atenção"
- Vermelho: #EF4444 para "proibido"
- Texto: branco suave (#E6EDF3)

**Layout Paradigm**:
- Header com navegação por abas (CVM / Meta / Melhores Práticas / Checklist)
- Grid de cards 2-3 colunas com métricas e status
- Seção de "Checklist Interativo" com checkboxes para o trader verificar compliance
- Sidebar direita com "Alertas Regulatórios" recentes

**Signature Elements**:
- Gauge/medidor de "nível de risco" visual para diferentes tipos de post
- Cards com badge de status (PERMITIDO / ATENÇÃO / PROIBIDO)
- Timeline de mudanças regulatórias com marcadores coloridos

**Interaction Philosophy**:
- Checklist interativo que o trader pode marcar enquanto prepara seu conteúdo
- Filtros para tipo de conteúdo (print de operação, análise, resultado mensal)
- Comparador visual: "Antes vs Depois" de um post corrigido

**Animation**:
- Contadores animados nas métricas
- Transições suaves entre abas
- Pulse animation nos alertas de atenção

**Typography System**:
- Títulos: Space Grotesk Bold — moderno e técnico
- Corpo: Inter Regular — leitura em tela otimizada
- Código/citações: JetBrains Mono — contexto técnico

## Ideia 3: "Legal Navigator" — Guia Editorial Sofisticado com Tipografia Expressiva

**Design Movement**: Editorial Magazine + Legal Documentation

**Core Principles**:
- Tipografia como elemento visual principal — grandes títulos com peso expressivo
- Layout de revista com seções bem delimitadas e espaçamento generoso
- Contraste entre zonas de conteúdo denso e zonas de respiro visual
- Paleta restrita de 3 cores com uso estratégico

**Color Philosophy**:
- Fundo: creme levemente aquecido (#F5F0E8) — remete a documentos jurídicos impressos
- Primária: verde-floresta escuro (#1C3B2D) — seriedade, crescimento, segurança
- Acento: dourado-mostarda (#C9A227) — destaque, atenção, valor
- Texto: quase-preto (#1A1A1A)
- Separadores: verde claro (#E8F0EB)

**Layout Paradigm**:
- Navegação horizontal no topo com links âncora para seções
- Hero section com título grande e subtítulo explicativo
- Seções alternando entre layout de coluna única (texto corrido) e grid (cards)
- Margem lateral direita com notas de rodapé e citações de fontes
- Footer com links para fontes oficiais (CVM, ANBIMA, Meta)

**Signature Elements**:
- Numeração de seções em estilo legal (§1, §2, §3)
- Pull quotes em tipografia grande com cor de acento
- Tabela comparativa "Permitido vs Proibido" com design de tabela editorial

**Interaction Philosophy**:
- Scroll suave entre seções com navegação sticky
- Expandir/colapsar detalhes de cada regra
- Botão "Copiar Disclaimer" para o trader usar diretamente em seus posts

**Animation**:
- Parallax sutil no hero
- Fade-in progressivo das seções ao scrollar
- Underline animado nos links de navegação

**Typography System**:
- Títulos principais: Playfair Display Bold — autoridade editorial clássica
- Subtítulos: Lato SemiBold — transição para leitura moderna
- Corpo: Lato Regular — leitura confortável e acessível
- Citações legais: Courier New — autenticidade documental

## Decisão Final

**Escolhida: Ideia 3 — "Legal Navigator"**

Justificativa: A estética editorial com tipografia expressiva (Playfair Display + Lato) cria a autoridade necessária para um guia de compliance sem ser intimidante. A paleta creme/verde-floresta/dourado é sofisticada e diferenciada, evitando os clichês de azul corporativo. O layout de revista com notas marginais e citações em destaque organiza bem o conteúdo denso de forma visualmente agradável. A funcionalidade "Copiar Disclaimer" agrega valor prático imediato ao usuário.
