# Template de Post Educacional sobre Operações com Opções

## 📌 Como Usar Este Template

Este template foi desenvolvido para ajudá-lo a estruturar posts sobre seu diário de operações de forma **educacional, segura e em conformidade com as regras da CVM e Meta**. 

**Instruções:**
1. Copie este arquivo e renomeie como `post_[DATA]_[ATIVO].md`
2. Preencha cada seção com informações específicas da sua operação
3. Antes de publicar, execute o **Checklist de Compliance** no final
4. Copie o conteúdo final para o Instagram/Facebook

## ✅ Checklist de Compliance

Antes de publicar, verifique cada item abaixo:

### Conformidade com a CVM

- [ ] O post foca em educação, não em recomendação de ativos específicos?
- [ ] Não há cobrança de mensalidade, assinatura ou taxa pelo conteúdo?
- [ ] A linguagem é descritiva (passado) e não imperativa (compre/venda)?
- [ ] Não há promessas de rentabilidade ou garantia de resultados?
- [ ] O disclaimer está incluído de forma clara e visível?

### Conformidade com Meta (Instagram/Facebook)

- [ ] Não há palavras como "garanto", "certeza" ou "infalível"?
- [ ] Os prints de ganhos têm contexto educacional explicativo?
- [ ] Não há linguagem apelativa que induz ao enriquecimento rápido?
- [ ] Se há parcerias comerciais, estão identificadas com #Publi ou #ParceriaPaga?
- [ ] O tom é profissional e responsável?

### Qualidade Educacional

- [ ] O post explica o raciocínio da operação, não apenas o resultado?
- [ ] Há menção ao risco envolvido na operação?
- [ ] O aprendizado é claro e aplicável para outros operadores?
- [ ] Não há linguagem que induz a seguir a operação?

### Antes de Publicar

- [ ] Revisei o texto duas vezes?
- [ ] Verifiquei a ortografia e a gramática?
- [ ] O disclaimer está visível e legível?
- [ ] Os números e datas estão corretos?

## 🚨 Sinais de Alerta — NÃO FAÇA ISSO

Se você reconhecer qualquer um desses padrões no seu post, **não publique**:

| ⛔ Não Faça | ✅ Faça Assim |
|---|---|
| "Garanto 10% ao mês com essa estratégia" | "Nesta operação, capturei 45% do prêmio" |
| "Todos conseguem fazer isso" | "Essa estratégia funcionou para mim naquele contexto" |
| "Comprem PETR4 agora" | "Entrei em PETR4 porque..." |
| "Siga minha operação" | "Documentei minha operação para fins educacionais" |
| Post com apenas print de lucro | Post com explicação do raciocínio + resultado + aprendizado |
| Sem disclaimer | Com disclaimer claro e visível |
